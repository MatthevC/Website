# MatthevC — MATT'S WORLD

## Struktura projektu

- `index.html` — strona
- `app.js` — logika strony
- `style.css` — wygląd
- `config.js` — konfiguracja
- `events/events.json` — lista eventów
- `pictures/logo/` — logo i grafiki marki
- `pictures/roles/` — grafiki VIP/moderacji
- `pictures/social/` — grafiki social/Discord
- `pictures/events/` — grafiki eventów

### Dodawanie eventu

1. Wgraj grafikę do `pictures/events/`.
2. Dodaj wpis do `events/events.json`.
3. W polu `image` wpisz ścieżkę, np.:
   `pictures/events/nazwa-eventu.png`

Nie przenoś plików graficznych do katalogu głównego.
